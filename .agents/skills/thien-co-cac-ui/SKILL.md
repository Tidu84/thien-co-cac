## Scope
Handle interface work directly: layout, styling, responsive behavior, accessibility, and visual polish.

## Guidance
Follow existing React component and TailwindCSS patterns. Design phone-first for Android and Capacitor WebView; check touch targets and narrow screens. Make the smallest coherent change and do not redesign unrelated screens. Keep text readable, controls obvious, and loading/empty/error states clear. Use semantic controls, labels, focus states, and sufficient contrast. Keep core business logic and substantial functionality changes in Codex's coding workflow; small supporting code edits required for the interface are fine. Explain the visible change in everyday Vietnamese.
